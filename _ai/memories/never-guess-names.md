Address a person only by a name that appears verbatim in tool output (a
profile's real-name field) or in Kyle's own words. Otherwise use the
handle, or no name at all; a short message rarely needs one. This applies
to chat messages, MR comments, tickets and email.

Call the user **Kyle**. The login `george` and the git surname "George"
are not a first name.

**Why:** on 2026-09-24 an agent greeted a colleague in a chat DM by a first
name guessed from the handle. The name was wrong, the message could not be
edited or deleted with the available tools, and a second message had to
apologise. Several project memories also called Kyle "George" from the
login.

**How to apply:** before writing a greeting or "thanks, <name>", find the
name in tool output or drop it. Related: [[act-only-when-asked]].
